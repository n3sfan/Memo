# Memo Mobile UI Redesign

Design boards generated for the Memo MVP mobile redesign. The visual direction
is a private memory atlas: tactile map-paper surfaces, deep ink text, moss
primary actions, muted coral danger states, and brass pin accents.

## Boards

1. `01-onboarding-auth.png` - splash, onboarding, permissions, OAuth sign-in.
2. `02-map-core.png` - personal map, pin preview, drop-pin mode, offline map.
3. `03-pin-editor-media-queue.png` - pin editor, coordinate validation,
   attachment sheet, media upload/offline queue.
4. `04-pin-detail-share-delete.png` - expanded pin detail, image viewer,
   share-link modal, delete confirmation.
5. `05-timeline-public-link.png` - timeline, selected timeline item, public
   shared pin, revoked public link.
6. `06-duo-map.png` - Duo setup, invitation, accept invite, active Duo
   management.
7. `07-settings-privacy.png` - settings, export data, delete account
   confirmation, deletion cleanup/retry.

## MVP Scope Covered

- OAuth auth flow.
- Personal map and bounding-box map view states.
- Pin creation, edit, detail, delete and map reveal.
- Image, text and audio attachment states.
- Offline cached data, upload queue and retry states.
- Timeline sorted memory browsing.
- Single-pin public share links and revoked-link handling.
- Duo Map for exactly two members.
- Privacy, export data, logout and account deletion.
